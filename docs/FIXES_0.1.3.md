# v0.1.3-preview.1 · 悬浮出行与城市细节

本轮对应实际试玩反馈，重点是滑翔、剩余载具外观和可走近查看的城市细节。最终原生导出验证、构建散列与截图见 [TESTING.md](TESTING.md)。

## 出行

- 滑翔机和滑翔伞创建后立即入座，保留足够高度与初速。修复新物理体解除冻结时丢失速度的问题；空中存档和加载也保留运动状态。滑翔仍会缓慢下降，不会无动力永久悬停。
- 三种航空载具增加独立几何：18m 翼展滑翔机、弧形滑翔伞及悬挂驾驶员、H160 风格直升机，包括座舱、尾桨、曲面机身及起落架。它们是按公开资料制作的原创游戏模型。
- 新增免费 Aether X1 反重力平衡车，200 km/h，自动越阶、掠水、R/F 手动升降、墙前辅助制动。它是科幻设定，无需燃料。
- 超跑 420、摩托 320、客机 800、直升机 350 km/h。数字是本版游戏调校，已用生产输入与实际刚体加速验证。
- 取消合成脚步声，保留环境、引擎和碰撞声音。
- 清理游戏停机坪内侵入旋翼空间的树冠，按整个树冠外包络检查，而非只看树干。
- 默认停放高度按新轮胎/起落架接地点设置，避免刚进入新世界就落地受损。旧世界因新建筑而被安全重定位时，同步清理待恢复速度，防止下一物理帧突然冲出。

## 实景细化

- **W Sydney**：Ribbon 曲面外立面、白色 W 标志、入口红色花形 W、铜色入口和玻璃细节。
- **ICC**：公共登记柜台、电子屏、木墙、吊顶、灯带、展厅桁架与铺面接缝。保留 Convention、Exhibition、TikTok Entertainment Centre 的可行走区域。
- **Sydney Tower Eye**：独立 309m 塔体、金色观景舱、窗格、支撑轴、56 条拉索和临街基座。到达点位于街面；未制作电梯和完整塔内游览。
- **Circular Quay**：Wharf 2–6 按地图分别定位和转向，14 个顶棚及 14 个亭廊保留真实平面轮廓，补入口、栏杆、路标、步行空间及滨水景观；车站另做花岗岩外墙、狭长窗带、上下层结构和公共柱廊；Eastbank、Searock、City Extra 分别制作店面。
- **Darling Square**：保留原有 12 个店面，新增 Auvers、Hakatamon、Chinta Ria，补白色波浪顶棚、种植区、长椅与铺装。恢复地图标签明确的住宅裙楼。
- 六家新增店面在地图中可选，导航指向已检查的公共门前，并提供可选游戏消费；总计 22 项城市体验。

[城市数据](CITY_DATA.md)和各模型参考文档分别标注真实平面、已公布尺寸和照片推断。城市尚未完成逐栋、逐店、逐室的一比一复刻，普通建筑外立面、地形、高架与地下系统仍有简化。公开照片无法证实的私有室内没有伪称为实测结构。

## 兼容与分发

九类载具继续免费新增独立副本并立即进入；之前的副本保留。两种模式初始 $50,000，旧世界只补足一次；任务和游戏消费保留。地图版本和模型版本更新至 3，对冲突位置进行安全迁移，保留 ID、血量、油量与用户存档。

新保存使用格式 5，仍能读取旧格式 1–4。v0.1.2 会拒绝格式 5，避免旧应用忽略滑板副本后覆盖新存档；仅载入旧文件不会重写它，首次成功保存时升级并保留原恢复副本。已用实际 v0.1.2 读取代码验证拒绝行为和文件字节保留。

发行目标是 Apple Silicon Mac，离线单人应用。其他操作系统尚未提供玩家构建。本包采用 ad-hoc 签名，未公证。
