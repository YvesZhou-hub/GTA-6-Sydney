这里记录的是开发工作区中实际运行并通过的组件测试，**不是最终导出 App 或 ZIP 的验收证明**。最终构建的源码哈希、签名、解压启动、完整玩家流程和原生截图应以单独的 `v013-app` 证据为准；本目录不作为安装包本身的验收证据。

逐项核对了源 JSON 的通过状态与对应运行日志；相关日志没有 `SCRIPT ERROR` 或 `ERROR`。有原始 JSON 的项目仅作路径脱敏；只有日志的项目显式标记 `source_type: summary_from_actual_passed_log`，保留检查名称和完成记录，不能视为原程序输出的 JSON。

15 组共 332 项检查；不同测试可能覆盖同一行为，因此不能解读为 332 个互不重叠的产品功能。

“原生局部”表示使用图形渲染器运行局部场景，不表示来自最终导出的 App。首批 15 组中，完整世界 READY 在滑翔、默认载具与停机坪净空报告对应的开发场景中得到确认；其余几何和迁移测试采用局部场景。最后四组的范围另列于下表。速度来自游戏物理中的指定控制条件，不是现实车辆认证数据。

停机坪检查采用游戏设定的 55m 操作净空，按完整树冠而非树干位置排除 29 个映射树实例；原始地理 JSON 未改变，报告保留被排除的 OSM 节点 ID。这是为了游戏可驾驶性进行的植被调整，不是现实停机坪规范或现状测量。默认 787 的宽包围盒仅用于筛选候选，最终用实际碰撞体和可见三角面检查，均未与 Gate06 相交。

ICC 的走行检查不等于已经还原全部会议室；W、悉尼塔等模型是有来源的程序化重建，不能据此宣称整城一比一或实测精度。环形码头/达令广场街景与完整城市定位结果补充在下表；最终导出结果单独记录在 v013-app 目录。

证据整理仅读取测试报告；没有读取玩家世界存档。用户名、本机绝对路径和隔离 QA 存档标识已替换；数值测量、坐标、检查结果和游戏资源路径保持原样。
