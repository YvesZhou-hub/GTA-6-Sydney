# 坦克与战机的游戏武器

Harbour Bastion 坦克与 Aster F-27 战机使用原创游戏武器、几何和爆炸效果。这些参数用于沙盒玩法，不表示真实武器性能，也没有导引、自动追踪或战术模拟。模型资料分别见[坦克参考](TANK_REFERENCE.md)与[战机参考](FIGHTER_REFERENCE.md)。

驾驶时按 **X** 或鼠标左键发射，也可以松开鼠标后点发射按钮。坦克炮塔跟随观察方向独立转动；**Q / Z** 左右辅助转动，**R / F** 抬高或降低炮管。炮管俯仰范围为 −12° 至 +70°。战机沿机鼻朝向发射，自由观察不会改变火箭方向。菜单、地图、暂停或离开载具时不能发射。

| 游戏参数 | 坦克炮弹 | 战机火箭弹 |
|---|---:|---:|
| 相对载具初速度 | 440 m/s | 1,350 m/s |
| 发射间隔 | 1.15 秒 | 0.35 秒 |
| 最长寿命 | 10 秒 | 7 秒 |
| 游戏重力 | 9.8 m/s² | 0 |
| 破坏能量参数 | 1.0 × 10⁹ | 1.2 × 10⁹ |
| 城市破坏半径参数 | 16 m | 22 m |

弹丸继承发射载具的速度。每个物理步从旧位置扫掠至新位置，排除发射载具和玩家；发射时还检查炮管起点至炮口之间的实体及炮口重叠，防止炮管穿过墙后从墙另一侧生成炮弹。命中调用正式主场景的 `apply_combat_blast`，由既有建筑与机场破坏系统处理可破坏组件、实体碰撞和存档；不会通过视觉爆炸代替实际损坏。未命中的弹丸到期直接回收。

准星通过同一弹丸参数预测炮口轨迹，包含载具速度和重力，不固定指向屏幕中心。主界面低频缓存预测结果：最多 32 条射线，其中一条用于炮管初始阻挡，其余 31 段近似曲线。该预测有分段近似误差，不是自动瞄准；实际命中仍由逐物理步扫掠确定。

效果包括短暂明亮爆心、无阴影局部灯光、扩张冲击环、稍后展开的烟尘、火星和碎片。固定预建 32 个弹丸槽、12 个爆炸槽；每个爆炸有 48 个批量视觉实例。弹池满时拒绝新发射，效果池满时复用最早轮转槽。效果碎片没有独立刚体，正式世界生成的持久碎石仍由世界原有上限管理。`impact_effect()` 只显示效果，用于主场景的撞击反馈，不会重复施加伤害。

## 接入与清理

`vehicle_weapons.gd` 是 `Node3D`，主场景调用 `setup(game)`，自身物理更新负责炮塔和弹丸。公开接口为 `fire_current()`、`update_aim(delta)`、`aim_point()`、`aim_status()`、`impact_effect(point, scale)`、`stats()` 和 `clear()`。

坦克模型提供 `_moving.turret`、其子节点 `_moving.barrel` 和炮口 `_moving.muzzle`；战机提供 `_moving.weapon_muzzle`。炮口局部 −Z 为出射方向。控制器同时验证当前载具、驾驶状态、生命值、冷却，以及主场景存在时的 `can_fire_weapon()`。手调偏置保存在各车 `weapon_aim_offsets` 元数据中；读档设置 `combat_restore_pose` 后，第一次控制按已加载的实际炮塔姿态重新计算相对镜头的偏置，避免首帧自动转回镜头。更换世界、读档或退出主菜单时主场景调用 `clear()`，释放弹丸中的旧载具弱引用与碰撞 RID，保留可复用节点池。

## 验证范围

`source/combat_weapons_test.gd` 的当前独立 headless 结果为 **49 / 49**，使用实际 Jolt 物理空间和一个精简的正式 `harbor_world.gd` 子类，不启动全城。覆盖 25 mm 薄墙、2,000 km/h 发射载具速度、炮管穿墙、炮口重叠、冷却和开火门禁、炮塔限位、Q/Z 准星变化、切车手调偏置、恢复后 60 个控制帧不漂移、寿命、池上限、清理，以及真实建筑组件破坏—恢复—序列化重载。开发证据在 `reports/combat-weapons/headless.json`，含该次测试源码摘要；该结果不是原生画面或全城性能验收。

复现：

```sh
tools/runtime/godot --headless --path game --script ../source/combat_weapons_test.gd
```

正式应用另有内部 `--combat-qa` 入口，加载完整主场景，调用真实载具生成、按钮连接和输入动作，对既有 OSM 建筑执行命中与损坏恢复，并写入 `user://combat-qa/report.json` 和对应截图。它使用未保存的专用测试世界；摄影时冻结载具，以固定物理步推进弹丸并记录爆炸年龄，不能作为飞行稳定性、真实操作系统鼠标输入或实时帧率测试。此文档编写时该完整应用验收尚未执行，最终结果由发布测试文档单独记录。
