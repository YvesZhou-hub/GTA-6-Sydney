# 悉尼夏季与游戏时间

默认 12 倍速：现实 7,200 秒走完游戏 24 小时。夏季平均白天约 13 小时 57 分，现实约 70 分钟；夜间现实约 50 分钟。太阳沿悉尼南半球的轨迹移动，夏季日出在东南、正午向北、日落在西南。

按 **T** 打开时间面板，拖动一天的时间，或选择日出、正午、金色时刻、日落晚霞、22:00 夜游。也可以前后移一小时、选择 1/6/12/24/60/120 倍速或定格拍照。面板释放鼠标并暂停驾驶；时间调整立即改变画面，退出后按选择继续循环。世界存档记录时间、速度、是否循环和天数，旧存档采用 16:00 / 12 倍速默认值。

`tools/calibrate_summer.py` 从 NOAA 的太阳位置公式计算 2026-12-01 至 2027-02-28 共 90 天，纬度 −33.8568°、经度 151.2153°，固定 AEDT UTC+11。算术平均得到日出 06:02:14、日落 19:59:36，太阳正午 13:00:55；再拟合固定季节赤纬，让运行时太阳在这两个时间准确穿过 −0.833° 的视日出/日落地平线。

这是以现实天文规律校准的**固定夏季体验**，不连接现实日期、天气或玩家电脑时钟。它不模拟当地地形遮挡、逐日大气折射或实时云况，也不是精确日历服务。

参考：[NOAA 太阳位置公式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)、[澳洲气象局季节说明](https://www.bom.gov.au/news-and-media/solstices-equinoxes-and-the-seasons)、[NSW 悉尼日出日落表](https://www.judcom.nsw.gov.au/publications/benchbks/local/perpetual_calendar.html)。NSW 表以 EST 列出，夏季比较时需要加一小时。

太阳方向与颜色、天空及其环境反射、曝光、雾色、窗灯随太阳高度渐变。F3 调整的数值以当前时段为基准保存乘数，因此不会在下一帧被时间系统覆盖。正常循环的天空反射增量更新最多每 0.5 秒一次；人工跳时立即刷新。昼夜切换不反复开关灯光、SSAO、SSR 或材质功能。
