# 战斗手感与难度曲线

这一轮不改武器种类和玩法结构，只调"打起来什么感觉"和"越打越难的节奏"。

## 打击反馈

| 反馈 | 何时出现 | 做法 |
| --- | --- | --- |
| 开火后坐 | 每次步行开火 | 镜头轻微上抬并回落，配合一次很小的抖动 |
| 击退 | 命中奶龙 | 沿命中方向推开，力度按伤害占其血量的比例；重装奶龙的抗性是轻型的两倍多，几乎推不动 |
| 受击抖动 | 玩家掉血 | 抖动强度按这一次掉了多少血；治疗和复活不会触发 |
| 受击方向 | 玩家掉血 | 准星外圈出现一段红色弧线指向攻击来源，1.6 秒后淡出，最多同时显示 6 段 |
| 血量告急 | 血量低于 45% | 屏幕四边出现红色渐变边框，越低越明显，中间区域不着色，不挡视线 |
| 爆炸震动 | 载具主炮、火箭等爆炸 | 按爆炸半径和与镜头的距离抖动，远处不震 |
| 击败 | 每次击败奶龙 | 按体型给一次小抖动 |

镜头抖动是在跟随镜头**算完之后**叠加的偏移，不会干扰原有的镜头平滑；抖动值会自行衰减，不会持续累积。

## 难度曲线

**每波清理数量**：原来是 8 + 2×已清波数（上限 18），第一波就要打 8 只。现在是 **6 + 2×已清波数（上限 16）**：第一波更快打完，后面稳定在 16，不再无限增长。

**敌人等级**：原来只看清理波数。现在同时看**已解放的港区**：

```
等级 = 1 + 已清波数 / 2 + 已解放港区 / 2   （再按难度 ±1，上限 30）
```

推进城市会让后续增援变强，和港区玩法连起来。已经在场的奶龙不会因此变强。

**战斗难度**（设置 → 战斗）：

| 选项 | 敌人血量 | 敌人伤害 | 同时在场 | 入场保护 | 击败奖金 | 等级 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 轻松 | ×0.78 | ×0.72 | −1 | ×1.5（18 秒） | ×0.9 | −1 |
| 标准（默认） | ×1.0 | ×1.0 | 不变 | ×1.0（12 秒） | ×1.0 | 不变 |
| 硬核 | ×1.30 | ×1.28 | +2 | ×0.55（6.6 秒） | ×1.25 | +1 |

难度只作用于**新出现**的奶龙，改设置不会让场上的敌人突然变强或变弱。

## 验证

```sh
tools/runtime/godot --headless --path game --script ../source/combat_curve_test.gd
tools/runtime/godot --path game -- --feel-qa
```

- `combat_curve_test.gd`（15 项）：每波数量、等级公式、港区与难度的影响、上下限、难度档位之间的单调关系。
- `--feel-qa`（17 项）：三档难度下**真实生成**的奶龙血量、伤害、奖金、在场数量与入场保护；解放港区后等级上升；轻型被击退而重装几乎不动；开火后坐、受击抖动、受击方向弧线的出现与淡出、低血量阈值；抖动只改镜头位置且会归零。结果写入 `user://feel-qa/report.json`，原生窗口下附带截图。
