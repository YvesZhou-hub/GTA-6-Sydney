# v0.4.0-preview.1：街上有人、城市有目标

这一版把城市"填满"了：人物换成真正的角色模型，街上有车流和行人，地面分出市区与公园，夜里路灯会亮；玩法上给了城市一个主线之外的长期目标——把被奶龙占住的港区一个个夺回来。存档格式仍为 7，旧世界可以直接继续。

## 人物与街道

- **人物换模**：主角和居民从方块小人换成带动作的角色模型，走、跑、站、挥手、中弹、倒地都有对应动作；手枪握在右手，跟着动作走。
- **车流**：车沿真实道路行驶，按澳洲习惯**靠左**，车道位置按每条路的实际宽度计算，路口优先直行，前方有车会停；车是实体，可以被撞到。
- **行人**：沿人行道行走；附近出现奶龙、或玩家开车高速逼近时会跑开。
- **设置 → 画面 → 街上人车**：关闭 / 正常（18 车 26 人）/ 热闹（30 车 44 人）。低配机器可以关掉。

## 城市细节与氛围

- **树**换成有枝干树叶的模型，替代原来的三个球形树冠。
- 沿宽度 9 米以上的道路摆放**路灯、长椅、垃圾箱**，路口有信号灯：全城约 1,960 盏灯、430 个小件。
- **地面分区**：用地图里的建筑轮廓生成"城市化"遮罩，市区地面是铺装灰，空地和公园保持草地，沙滩保持沙色。公园里撒了灌木和草丛。
- **夜晚**：路灯灯头会亮，玩家附近十盏灯是真实光源，地面有光斑；建筑窗户和店铺照常亮灯。

## 玩法：夺回港区

全城九个港区被奶龙占据，从环形码头开始逐个夺回：

- 在港区内击败一只奶龙 +1，完成一份工作或城市体验 +2；范围外不计，未开放的港区不能提前推进。
- 清空后该港区**解放**：发放奖励（$6,000 起，越往后越多），开放下一个港区。
- **街面会变**：被占据时街上人车只有平时的 70%（未开放 55%），解放后 140%。
- 小地图下方显示当前港区进度，暂停菜单 →「城市与港区」查看全部港区并导航。
- 新增成就：夺回第一个港区、港城解放。

详见 [港区解放](DISTRICTS.md)。主线第一章「港城第一天」仍然是新手引导。

## 界面

- 菜单统一了视觉：主要按钮是金色填充，次要按钮是描边；鼠标悬停、按下和手柄选中都有明显反馈。
- 标题界面先给"怎么开始"，暂停菜单按用途分组，不再是一长串一模一样的按钮。
- 底部提示、载具说明、生存卡片等会显示你当前的按键（v0.3.0 起）。

## 兼容与已知限制

- 存档格式仍为 7。新增 `districts` 字段；旧世界读进来时全城仍被占据，从第一个港区开始。
- 启动时间约 14 秒（v0.3.0 约 13 秒），多出来的是模型、街道小件和地面遮罩。
- 安装包体积增加约 20 MB（新增第三方模型）。
- 第三方模型全部为 CC0 公共领域素材，来源见 `game/assets/thirdparty/SOURCES.md`。
- 手柄仍未在实体设备和 Steam Deck 上实测；Windows 自动验收为无界面模式，不代表已实测 Windows 显卡画面与声音。
- 奶龙造型未改动。

实际验证结果见 [验证记录](TESTING.md)。
