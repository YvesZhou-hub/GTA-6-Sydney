# v0.1.9 · 漂移、急刹、三倍加速与载具耐久

跑车、摩托车新增 **Ctrl + A/D 漂移**，松开后平顺恢复抓地，也可以反打。**空格急刹**立即切断驱动力，即使继续按 W / Shift 也能停车；摩托车低速转弯更快，高速保持平顺，倾斜不会把轮胎侧向力错误地变成向上推力。

全部载具可以按住 **Shift 加速**，目标速度上限提高到原基准的三倍，松开后通过物理力平顺回落。跑车 420→1260 km/h、摩托车 320→960、平衡车 200→600、战斗机 2000→6000；漂移时也按总地面速度计算上限。其他载具与滑翔类基准见 [驾驶说明](DRIVING.md)。这是游戏的辅助加速，不是现实载具性能。

车辆轻微擦碰不再扣耐久；中等撞击约 21 次才会耗尽耐久，强烈单次撞击最多扣 12%。持续顶住同一堵墙只算一次，离开再撞才会重新计入。急刹和漂移产生的切向摩擦冲量不再误计成撞击。现有系统使用整车耐久与外观损伤，没有独立的轮胎爆胎计数。

**磁悬浮平衡车完全免疫破损**：撞击、跌落、入水都不掉耐久、不留下黑色凹痕、不变色或冒烟；旧存档的受损平衡车载入时恢复，位置、身份、燃油与悬浮高度保持。它仍与实体墙壁碰撞，并会主动减速避障。

地图、城市与载具模型沿用原有版本；本轮没有宣称增加城市还原精度。Mac、Windows 发行包的实际验证范围分别记录，旧版宣传片仍展示 v0.1.8 内容。
