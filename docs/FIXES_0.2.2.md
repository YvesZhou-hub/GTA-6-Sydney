# v0.2.2-preview.1：选装武器、飞行奶龙与渐进难度

本版在原有持续追击玩法上增加了载具武器选择，让击杀金币可以继续用于扩充和升级装备。现阶段为预览版；以下内容对应当前源码，最终安装包验证状态见文末。

## 本轮变化

- **清晰血条与实际扣血浮字**：每只敌人显示等级、当前 / 最大生命值、金色扣血尾条与锁定提示。爆炸浮字跟随各自受伤目标，准确显示中心和边缘实际损失；高速连击短时间合并，击杀金币与伤害分开显示。界面会避开主 HUD 和地图，墙后敌人不透视显示。
- **四种付费选装模块**：机关枪、微型范围炮、激光和连锁闪电，分别使用曳光弹、范围爆炸、精准光束和逐跳电弧。各有独立伤害、射程、装填和升级参数。
- **每车型三个额外槽位，每模块三级**：11 类载具均可选装，同一种模块最多装一件。原有免费自动副炮继续保留，不占槽。
- **买后可以免费装卸，同款共享**：首次购买有空槽就自动装配，满槽则入库；卸下保留等级，其他车型分别解锁。金币不足、满级或无效装配不会扣钱。
- **全部弹药免费**：V 统一控制所有自动武器，默认开启；坦克、战斗机的强力主武器仍由玩家手动发射。B 的暂停菜单可以购买和升级。
- **物理命中与遮挡**：机关枪和范围炮有真实飞行时间；炮击以实际撞击点为中心，边缘伤害减弱；激光与每一段闪电都检查障碍，闪电每跳保留上一跳 72% 的伤害。
- **两种飞行奶龙**：轻翼奶龙俯冲，雷翼奶龙蓄力范围电击；分别有 1.0 秒、1.6 秒攻击前摇。它们参与真实碰撞、扣血与金币奖励，并与地面敌人共享数量上限。
- **难度随进度和装备成长**：装备压力按每 18 秒有效战斗时间逐级适应，最高 Lv.30；低血量、入场保护和暂停期间不继续积累装备升阶时间。购买装备不会给场上怪物补血，只影响后续增援。
- **保留持续战斗规则**：附近补怪不依赖上一轮全部清空，离开区域后可回收不可见残怪腾出全局 24 个位置；回收不伪造击杀或金币奖励。
- **修复低空悬停的补怪空档**：下方近战怪够不到载具时，不再占满附近预算阻止飞行增援。满额时仅按缺口回收不可见、无法接战的残怪，保留眼前敌人和当前飞行追击。
- **存档格式 7**：保存按车型共享的模块、等级、装配与难度进度，可读取旧格式 1–6。v0.2.1 旧读取器会拒绝格式 7，避免新模块数据被旧程序覆盖丢失。

详细价格、三级参数、按键与应对方式见 [载具武器与空中敌人](ARSENAL.md)。H 的步行急救 / 驾驶战地快修，以及 B 的维修、补给和原有主武器火控升级继续保留。

## 防止装配操作绕过射速

付费模块的剩余装填在切换 V、换同款或不同款载具、卸下再装回后保留。暂停菜单和关闭自动武器时不累计付费装填进度。升级不会改变已经发出的弹丸参数，换车会清理旧弹丸与锁定。

为这些路径增加了实际生产系统回归：连续切换 V、反复换车、真实菜单交易卸装和暂停后，范围炮均未提前发射或额外扣费。测试中 I 级范围炮第二次发射出现在累计有效时间 2.45 秒，符合其 2.40 秒装填下限和离散帧更新。
