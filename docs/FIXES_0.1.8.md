# v0.1.8-preview.1 · 中文字体、炮击反馈与项目宣传片

车辆菜单中“无敌坦克”“无敌战斗机”的“敌”字曾显示为缺字框。现在启动页、菜单、自绘地图及默认三维招牌共享随包提供的 Noto 字体链，完整许可一同分发。实际 TextServer 字形检查、原生界面截图与首次导入检查见 [字体修复](UI_FONTS.md)。原车辆名称保持不变。

坦克现在有真实炮口喷焰和视觉后坐；命中分为短促闪光、沿命中表面的尘浪、飞散碎片、烟尘上升和消散。烟尘使用本项目生成的透明纹理，颜色和透明度在游戏着色器中计算。新增空间音效由游戏代码合成。火花、冲击环、碎片和火箭亮线改为沿模型自身轴缩放，避免旋转后的非均匀缩放把飞散方向拉歪。仍使用有上限的效果池，原炮弹扫掠、构件破坏和损坏存档接口保留。[炮击实现与范围](COMBAT_EFFECTS.md)

项目宣传片为横屏实机录制，展示开炮与建筑损坏、歌剧院和海港大桥、跑车、战斗机、可步行台阶、公共室内以及夏季时间调整。镜头由录制脚本编排，使用生产世界、车辆、武器和时钟；定时采样用于导出，不表示本机实时帧率。字幕与原创配乐在剪辑阶段加入，生产武器音效对齐实际记录的开火和命中事件。[录制与剪辑方法](PROMO.md)

同一版本现提供 Apple Silicon Mac 与 Windows x86_64 预览；Windows 补充包及独立验证见 [Windows 说明](WINDOWS.md)。普通楼宇、地形和室内有简化，未达到全区 1:1；建筑破坏是游戏构件系统，不是工程结构仿真。视频不是播放量或传播效果的保证。
