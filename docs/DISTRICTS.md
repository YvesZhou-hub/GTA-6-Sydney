# 港区解放：城市的主循环

奶龙占着悉尼的各个港区。玩家一个港区一个港区地夺回来：在港区里击败奶龙、或在这里完成工作和城市体验，都会推进清剿进度；进度满了这个港区就**解放**，街上的人和车回来，发放奖励，并开放下一个港区。

## 规则

- **怎么推进**：在港区范围内击败一只奶龙 +1；完成一份工作或一次城市体验 +2。范围外的击杀不计入，未开放的港区也不会提前推进。
- **顺序**：第一个港区一开始就开放，之后每个港区要等前一个解放。
- **街上的变化**：奶龙占据时街上人车只有平时的 70%（未开放的港区 55%），解放后变成 140%，能直接看出来。
- **界面**：走进任何一个港区，小地图下方出现港区卡片，显示名称、进度条和该做什么。暂停菜单 →「城市与港区」可以查看全部港区状态并导航过去。
- **成就**：解放第一个港区解锁「夺回第一个港区」，九个全部解放解锁「港城解放」。
- **存档**：进度和已解放的港区写入存档（新增 `districts` 字段，不改存档格式版本）。老存档读进来时全城仍被占据，从第一个港区开始。

## 和主线、奶龙危机的关系

- 主线第一章「港城第一天」仍然是新手引导，教会开车、导航、拍照、工作和战斗。
- 奶龙危机负责战斗本身（刷新、等级、武器升级）；港区解放把这些战斗变成**有目标的推进**：打哪里、为什么打、打完有什么变化。
- 自由观光模式没有奶龙，港区进度只能靠工作和城市体验推进。
