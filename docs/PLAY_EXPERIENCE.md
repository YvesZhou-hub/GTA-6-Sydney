# 轻松探索悉尼：资金与城市体验

生活模式和沙盒的新世界都有 **$50,000 游戏资金**。跑车、摩托车、快艇、游艇、滑翔伞、滑翔机、直升机和客机全部免费；资金不足也不会锁住交通工具。载具菜单的安全生成和立即驾驶由主场景处理，经济接口兼容旧版购买调用，不再扣除载具费用。

旧世界首次使用新版经济时，低于 $50,000 的余额只补足差额；高于这一金额的余额完整保留。补助记录为 `economy_version=1` 和 `welcome_grant`，随世界保存。花掉资金后重新载入不会再次补满。原有工作进度、已赚收入、完成记录、货物、NPC 记忆和自有物品保留；补助不计入工作收入。未完成的旧工作也享受提高后的基础报酬。

| 工作 | 基础游戏报酬 |
|---|---:|
| 海港摄影漫步 | $1,500 |
| 旧物回收 | $2,000，按箱体完整度结算 70–100% |
| 码头巡检 | $2,200 |
| 空中观察 | $3,000 |
| 两岸计时赛 | $2,000，加计时奖金 |

餐饮和场馆提供可选的游戏消费：ICC Convention、ICC Exhibition、TikTok Entertainment Centre、Darling Square 的 12 家已制作店面，以及 Manly 海边野餐，共 **16 项**。每次 $12–120，恢复 35–90 点耐力，并留下可保存的旅行印章和消费记录。步行或停车靠近即可体验，无需强制下车，没有等待计时或购买冷却。短暂的场景文字反馈会在五秒内淡出，不限制移动或再次选择。

**所有价格、食物消费、纪念票和体验结果都是游戏设定，不是真实菜单价格、订单、演出、门票或预订。** 剧场体验发放游戏纪念票并提示探索已可进入的观众厅和舞台；它不声称正在播放现实节目。普通商铺在已核实位置的门前提供游戏服务，未制作的商铺内部不会因为消费而开放。

位置直接使用组装后世界中的入口/门前锚点，缺少锚点时不会在默认坐标生成服务。依据见 [ICC 参考](ICC_REFERENCE.md)、[Darling Square 店面参考](DARLING_SQUARE_REFERENCE.md) 和 [Manly 参考](MANLY_REFERENCE.md)。这些资料支持地理位置和已建空间；不代表商户授权、即时营业状态或实时活动排期。

## 主场景接口

`service_catalog()` 返回当前世界可用服务，包括稳定 `id`、`anchor`、`position`、`radius`、`cost`、`stamina_restore`、`description`、`notice` 和 `visits`。`nearest_service(position)` 返回范围内最近一项，找不到时返回空字典。

`use_service(id, position, on_foot=true)` 校验距离、停车状态和余额。每次成功调用仅扣款一次、记账一次，并且仅发出一次 `service_completed(result)`；失败不扣款或发放奖励。已乘坐载具时传 `false`，速度来自主场景每帧的 `tick_context`。停车阈值为 3 m/s。主场景仅在信号处理器中应用 `result.effects.stamina_restore`，夹取至玩家耐力上限；不要再根据返回值重复发奖。`notification` 提供完成文字，`interact` 在附近返回 `OPEN_SERVICES` 供主场景打开菜单。

消费在两种模式下均使用游戏资金。载具始终免费；普通维修/修缮的既有沙盒免费行为保持。`get_state()` 的生活数据版本为 3，另保存 `experience_visits`、`experience_spending`、`last_experience`；载入记录不会重播消费信号、奖励或场景效果。

## 实测

`source/life_experience_test.gd` 在独立小场景中通过 **40/40** 项检查，日志为 `reports/life-experience.log`：两种模式起始资金、八类载具零余额调用、旧余额和工作迁移、实际临时 JSON 写入/读取、消费后不重复补助、不重复发奖、16 项服务、停车购买、资金不足、缺失地点、五种空间工作完成及收入保存均通过。测试没有读取、覆盖或删除用户世界存档，也没有启动原生渲染窗口。
