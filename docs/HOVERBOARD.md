# Aether X1 · 反重力平衡车

原创科幻载具，不对应现实产品。按 Tab 免费新增并立即驾驶，已有副本保留。无需燃料，生命值降低不会切断反重力驱动。

- W/S 前进或后退，A/D 转向；前进上限 200 km/h，倒车 43.2 km/h。
- 空格快速制动。转向速度随车速降低，让高速操作更容易控制。
- 自动保持约一米的车体离地高度，向前探测台阶并提前抬升；可掠过海港水面。
- R/F 增减相对地面的悬浮高度，松开后保持。额外高度范围 0–180m。
- 无法越过的实体墙触发提前制动；实体仍有碰撞，没有把建筑关闭或变成可穿透状态。它不是完整的自动避障驾驶，复杂尖角和狭窄开口仍需玩家转向。

车体包括金属分层甲板、两块防滑脚垫、四个发光推进舱、状态屏、灯带以及随占用显示的站立驾驶员。模型用原创程序化几何生成，未使用第三方模型或贴图。

悬浮力、水平加速和姿态控制作用于生产 `RigidBody3D`，不靠每帧平移坐标穿过台阶。前向射线探测和制动距离随真实速度变化。保存包含独立 ID、位姿、损伤和升高量；载入后仍是同一辆平衡车。

验证脚本：`source/hoverboard_test.gd`；导出 App 内使用 `-- --mobility-qa`。固定场景验证实际加速到 200 km/h、制动、转向、24 级实体台阶、水面、手动升降、54m 高架上额外升高 180m 后稳定悬停、存档和墙前制动。具体最终构建结果见 [TESTING.md](TESTING.md)。这些固定场景不等同于已验证城市每一处楼梯。
