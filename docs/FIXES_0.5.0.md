# v0.5.0-preview.1：打得有手感，港区会求助

这一版有三块改动：
- 战斗打起来更有反馈；
- 奶龙出手有了节奏，还多了一种新敌人；
- 港区会不定时发出限时求助，给你一个马上去做的小目标。

存档格式仍为 7，旧世界可以直接继续。

## 战斗手感

- **开火后坐**：步行开枪时镜头轻微上抬再回落。
- **受击反馈**：掉血时镜头抖动，掉得越多抖得越厉害。准星外圈会出现红色弧线，指向打你的方向。
- **血量告急**：血量低于 45% 时，屏幕四边出现红色边框，越低越明显，中间不挡视线。
- **爆炸和击败**：附近爆炸会震一下镜头，远处的不震。击败奶龙时按它的体型给一次小抖动。
- **击退**：打中奶龙会把它往后推，小的推得远，重装奶龙几乎推不动。奶龙蓄力出手时不会被推开。

## 奶龙的攻击节奏

每次出手都变成「预警 → 出手 → 收招」三段：

- 喷吐奶龙会**连喷三发**，走位能躲掉后两发。
- 首领奶龙和雷翼奶龙会**连打两下**，第一下之后别马上贴上去。
- 每种奶龙出手后都会**僵住一小会儿**，这是你还手的最好时机。

每一轮的总伤害、以及「预警 + 冷却」的时长都和 v0.4.0 一样，所以压力没有变大，只是更好读、更好躲。

## 新敌人：跳袭奶龙

- 头上扎橙色头带、膝盖有护垫，一眼能认出来。
- 离你 9 米以内会先**蹲下蓄力 0.8 秒**，头顶显示「起跳预警」，然后扑向你蓄力开始时站的位置。
- 落点 2 米内才算打中，所以**蓄力时往旁边走开就能躲掉**。
- 落地后僵直 0.6 秒。
- 敌人等级到 3 级后才出现在增援里，前期节奏不变。

## 难度曲线

- **每波数量**：第一波从 8 只改为 6 只，之后每波 +2，最多 16 只，不再一直涨。
- **敌人等级**：不只看打了几波，也看解放了几个港区。推进城市，后面的增援会更强。
- **设置 → 战斗 → 战斗难度**：轻松 / 标准 / 硬核，分别调整敌人血量、伤害、同时在场数量、入场保护时间和击败奖金。只影响新出现的奶龙。

详见 [战斗手感与难度曲线](COMBAT_FEEL.md)。

## 港区限时求助

待在一个已开放、还没解放的港区里，大约一分钟后会收到一次**限时求助**，有 3 分钟完成：

| 事件 | 什么时候出现 | 要做什么 | 奖励 |
| --- | --- | --- | --- |
| 奶龙围攻 | 奶龙危机模式 | 在标记点附近击退 5 只奶龙 | +$3,000，港区清剿 +3 |
| 巡查 | 任何模式（自由观光也有） | 走访 3 个标记点 | +$3,000，港区清剿 +3 |

- 地图会标出目标点，港区卡片显示进度和倒计时。
- 超时只是结束，不扣进度；开车离开这个港区会自动取消。
- 同一时间只有一个，结束后至少隔 150 秒才有下一个。

详见 [港区解放](DISTRICTS.md#限时求助事件)。

## 兼容与已知限制

- 存档格式仍为 7。进行中的求助不写入存档，读档后不会保留。
- 新增设置项「战斗难度」，旧设置文件读进来默认是「标准」。
- 手柄仍未在实体设备和 Steam Deck 上实测。Windows 自动验收用的是无界面模式，不代表已经实测过 Windows 上的画面和声音。
- 奶龙造型没有改动。跳袭奶龙只在原有造型上加了头带和护膝。

实际验证结果见 [验证记录](TESTING.md)。
