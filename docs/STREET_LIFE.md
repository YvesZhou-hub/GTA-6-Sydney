# 街上的车流与行人

城市原本只有玩家和 8 位有名字的居民，街道是空的。现在玩家附近会持续出现来往的车辆和行人，离开后自动收回，不写进存档。

## 规则

- **车走真实路网**：用地图里的道路中心线，按澳洲习惯**靠左行驶**，车道偏移按每条路的实际宽度计算。到路口时优先直行，没有可走的路就收回重生成。
- **前方有障碍会停**：车头有一条 9 米的探测线，前面有车或玩家的载具就减速停下，让开后继续走。
- **车是实体**：会被玩家的车撞到、推动，不会穿模。
- **行人走人行道**：沿道路两侧、按路宽偏移的位置行走，走到终点就换一条路线。
- **会被吓到**：附近出现奶龙，或玩家开车高速逼近时，行人会加速跑开，几秒后恢复正常。
- **只在身边生成**：26–115 米范围内出现，超过 190 米回收。数量恒定，不会越积越多。

## 设置

设置 → 画面 → **街上人车**：

| 选项 | 车 | 行人 |
| --- | ---: | ---: |
| 关闭 | 0 | 0 |
| 正常（默认） | 18 | 26 |
| 热闹 | 30 | 44 |

## 性能

Apple M4、完整城市、原生窗口，“热闹”档实测 29 辆车 + 41 个行人时平均 **12.41 ms 一帧**（约 80 帧）。低配机器可以调成“正常”或“关闭”。

## 与验收的关系

所有自动验收（驾驶、生存、遭遇、武器、主线、HUD）测量的是生产逻辑的位置、碰撞与刷新，流动的车辆会干扰这些测量，因此**验收模式下默认关闭**街上人车，只有 `--street-qa` 会显式打开。

## 验证

```sh
tools/runtime/godot --path game -- --street-qa
```

检查路网索引、车辆与行人生成数量、车辆是否始终在道路上、行人是否在道路两侧、车辆确实沿路线行驶、受惊后跑开、离开后回收、三档设置生效，以及“热闹”档的帧时间。结果写入 `user://street-qa/report.json`，原生窗口下附带截图。
