# 街上的车流与行人

城市原本只有玩家和 8 位有名字的居民，街道是空的。现在玩家附近会持续出现来往的车辆和行人，离开后自动收回，不写进存档。

## 规则

- **车走真实路网**：用地图里的道路中心线，按澳洲习惯**靠左行驶**，车道偏移按每条路的实际宽度计算。到路口时优先直行；快走完当前路线时会自动往前接下一段路，不会开到半路突然消失。
- **遵守地图上的交通规则**：步行街、人行道、自行车道不进车（全城 511 段）；单行道只按地图标注的方向行驶（全城 3,410 段，环岛和高速默认单行）。路口也只会拐进允许进入的方向。
- **车头朝前**：车辆模型的车头原本朝反方向，看起来像在倒车，已修正。
- **前方有障碍会停**：车头有一条 9 米的探测线，前面有车或玩家的载具就减速停下，让开后继续走。
- **车是实体**：会被玩家的车撞到、推动，不会穿模。
- **行人走人行道**：沿道路两侧、按路宽偏移的位置行走，也可以走步行街，走到终点就换一条路线。人物（包括主角和居民）的模型原本也是背朝行进方向，已一并修正。
- **会被吓到**：附近出现奶龙，或玩家开车高速逼近时，行人会加速跑开，几秒后恢复正常。
- **只在身边生成**：26–115 米范围内出现，超过 190 米回收。数量恒定，不会越积越多。距离按车和人**实际出现的位置**判断；以前按路段中点判断，长路段的一端可能就在玩家身边，车会凭空出现在旁边。

## 街道小件与树木

- **树**换成了带枝干和树叶的模型（3 种随机、随机朝向），替代原来的三个球形树冠。用于直升机停机坪净空判定的树冠范围保持不变。
- 沿宽度 9 米以上的道路，每 34 米交替两侧放一盏**路灯**，每隔几盏加一个**长椅**或**垃圾箱**；三条以上道路交汇的路口放**信号灯**。全部用批量绘制，按区块在 900 米外隐藏。
- 实测全城约 1,960 盏路灯、430 个小件；启动时间增加约 1 秒。

## 设置

设置 → 画面 → **街上人车**：

| 选项 | 车 | 行人 |
| --- | ---: | ---: |
| 关闭 | 0 | 0 |
| 正常（默认） | 18 | 26 |
| 热闹 | 30 | 44 |

## 性能

Apple M4、完整城市、原生窗口，“热闹”档实测 29 辆车 + 41 个行人时平均 **12.41 ms 一帧**（约 80 帧）。低配机器可以调成“正常”或“关闭”。

## 与验收的关系

所有自动验收（驾驶、生存、遭遇、武器、主线、HUD）测量的是生产逻辑的位置、碰撞与刷新，流动的车辆会干扰这些测量，因此**验收模式下默认关闭**街上人车，只有 `--street-qa` 会显式打开。

## 验证

```sh
tools/runtime/godot --path game -- --street-qa
```

检查路网索引、车辆与行人生成数量、车辆是否始终在道路上、行人是否在道路两侧、车辆确实沿路线行驶、受惊后跑开、离开后回收、三档设置生效，以及“热闹”档的帧时间。在真实悉尼地图上另外检查：步行街与单行道规则确实进入交通系统、每辆车都不进步行街且单行道方向正确、每辆车都在生成圈内出现、每辆车的前轮都在行驶方向前方。共 17 项，结果写入 `user://street-qa/report.json`，原生窗口下附带截图。

```sh
tools/runtime/godot --headless --path game --script ../source/street_rules_test.gd
```

在一个手工搭建的小路网上逐条验证：不进步行街、单行道方向、路口只拐进允许的方向、长路段只从远端出生、行人可以走步行街、路线能向前延长、车的前轮和人物的脸朝向行进方向（10 项）。
