# 设置、手柄与界面

Esc（手柄 Start）→ 设置与操作。所有修改立即生效并保存在 `user://settings.json`；无法识别或越界的旧值会回到默认。

## 画面

| 设置 | 选项 | 说明 |
| --- | --- | --- |
| 显示模式 | 窗口 / 全屏（无边框）/ 独占全屏 | |
| 垂直同步 | 开 / 关 | |
| 帧率上限 | 不限制 / 30 / 60 / 120 / 144 / 240 | 省电或减少风扇噪音时可限制 |
| 渲染分辨率 | 100% / 85% / 75% / 67% / 50% | 低于 100% 时用 FSR 1 放大 3D 画面，界面保持清晰 |
| 抗锯齿 | 关闭 / FXAA / MSAA 2×（默认）/ MSAA 4× / TAA | TAA 首次开启要编译着色器，会停顿数秒 |
| 画质 | 轻盈 / 标准 / 精细 | 阴影、环境光遮蔽、反射 |
| 街上人车 | 关闭 / 正常（默认）/ 热闹 | 附近街道的车流和行人数量，详见 [街上的车流与行人](STREET_LIFE.md) |
| 视野 | 55°–95° | 默认 68° |

没有提供 FSR 2：它需要运动矢量管线，完整城市首次切换时实测冻结 8–68 秒。

## 战斗

| 设置 | 选项 | 说明 |
| --- | --- | --- |
| 战斗难度 | 轻松 / 标准（默认）/ 硬核 | 只影响新出现的奶龙：血量、伤害、同时在场数量、入场保护时间和击败奖金，详见 [战斗手感与难度曲线](COMBAT_FEEL.md) |

## 声音与操作

- 主音量；切到其他窗口时静音。
- 鼠标灵敏度、手柄视角速度、反转垂直视角、加大提示文字。
- 键盘按键可逐项重绑定。成对动作共用一个键（奔跑与 3 倍加速、跳跃与刹车、飞行升降与炮管俯仰）。与其他动作冲突时会提示，但允许保留。“恢复默认按键”清除全部自定义。
- 底部操作提示、载具说明、生存卡片按钮、小地图、导航文字和主线目标都显示当前键位；改键后立即更新，并按键盘布局显示实际按键。

## 手柄（Xbox 布局；PlayStation、Switch Pro 与 Steam Deck 按对应位置）

| 输入 | 步行 | 驾驶 |
| --- | --- | --- |
| 左摇杆 | 移动 | 油门、转向 |
| 右摇杆 | 视角 | 视角 |
| A | 跳跃 | 刹车 |
| B | 互动 / 上车 | 离开载具 |
| X | — | 漂移 |
| Y | 载具菜单 | 新增载具 |
| RT | 反击 | 开火 |
| LT / L3 | 奔跑 | 3 倍加速 |
| RB / LB | — | 飞行升降、炮管俯仰 |
| 十字键 ↑ ↓ ← → | 地图、急救、工作、整备 | 地图、快修、工作、整备 |
| R3 | 自动武器开关 | 自动武器开关 |
| Back / Start | 城市体验 / 暂停 | 同左 |

菜单中用十字键或左摇杆移动焦点，A 确认，B 关闭。使用手柄时底部提示自动切换为手柄按键。地图上的自由标点仍需鼠标。

## 界面布局

- 画面按窗口比例铺满，16:9、16:10、21:9 都不再留黑边；界面按 900 高度等比缩放。
- 左侧状态、主线目标、提示与生存卡片自动上下排列；载具读数、消息与底部提示都有底板，底部提示在宽屏上限制最大宽度。
- 导航目的地文字固定在底部提示上方、生存卡片右侧，底部提示变成两行时也不会被遮住。

## 验证

```sh
tools/runtime/godot --path game -- --hud-qa
```

在 1280×720、1280×800（Steam Deck）、1440×900、1920×1080、2560×1440、2560×1080 下步行与驾驶各截一张图，设置一个长名称导航目标，检查 HUD 元素（含主线目标卡片与导航目的地文字）互不重叠、不超出画面、画面比例与窗口一致；并检查设置清洗、FSR 1 切换不停顿、视野、按键重绑定与恢复、改键后操作提示同步更新、手柄 Start/B 菜单和右摇杆视角。结果写入 `user://hud-qa/report.json`。
