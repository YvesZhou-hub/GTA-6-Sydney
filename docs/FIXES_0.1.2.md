# v0.1.2-preview.1 · 自由探索与载具更新

点击新增载具后，系统先为新的独立副本找到安全空间，再直接进入驾驶位。旧载具保留原位置；无需下车或寻找新车。所有八类载具在两种模式下均免费，零余额也可使用。附近放不下客机时提供机场位置，船艇使用开阔水面；没有空间时保留当前驾驶状态并提示原因。

新世界带有 $50,000 游戏资金。旧世界首次更新时仅补足不足部分；重复载入不会把花掉的钱重新补满。摄影、回收、巡检、飞行观察和竞速可重复进行，基础报酬 $1,500–3,000。K 打开 16 项餐饮、场馆和海滨体验，花费 $12–120 恢复耐力并保存旅行印章。当前场馆体验是消费反馈和已建空间探索，没有影片播放或完整演出。[经济与体验](PLAY_EXPERIENCE.md)

常驻小地图显示位置、朝向和目的地方向。M 打开同一地理数据的大地图，选择 37 个已制作地点、已标注的地图地点或任意位置；屏幕标记、罗盘和距离共同指引，导航目标随存档保留。大地图标点不移动人物；这与主动新增载具并进入驾驶位是两种独立操作。目的地建筑的图标与可抵达入口分别记录。[地图操作](NAVIGATION.md)

超跑、运动摩托和大型客机按官方照片与尺寸重新制作；豪华快艇和多层游艇提供两种不同的体量、甲板布局和水上操纵。车辆与飞机具有更明确的灯组、轮毂、座舱、进气口、风挡、舷窗、发动机风扇及起落架。它们是原创程序化重建，不是厂商 CAD 或扫描资产。[车型依据](VEHICLE_REFERENCE.md) · [船艇依据](BOAT_REFERENCE.md)

大桥四座石塔、主拱位置和歌剧院朝向按地图来源校准；北引道沿真实 Bradfield Highway 平面曲线重建。桥面连续碰撞面与 Jolt 接触处理修复弯曲引桥接缝的异常弹跳；任务只统计当前驾驶载具造成的撞击，停放车辆的事故不会扣掉玩家的竞速奖金。银行、ICC、W Sydney 等地点的建筑中心和公共到达点也完成分离，避免把玩家引到封闭楼体内部。[地理校准记录](GEOGRAPHIC_ALIGNMENT.md)

存档升级为格式 4，仍读取格式 1–3。较大的新模型会检查旧泊位净空，必要时移动静止旧副本并保留 ID、油量、损伤和驾驶关系。升级检查从原接地层面开始，保留安全桥下停车与空中飞行状态。测试使用独立 QA 世界，不覆盖玩家存档。

真实地图来源、照片参考与估计细节分别记录。当前道路没有完整交通规则/信号、现实高差和交通流，普通外立面与部分室内仍有简化，不能作为一比一现实或驾考训练完成版。平台、最终构建与实测证据见 [验证记录](TESTING.md)。
