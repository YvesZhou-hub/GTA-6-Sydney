# v0.1.7-preview.1 — 城市细节、夏季日夜与战斗载具

制作范围沿用机场、Sydney CBD / Darling Harbour / Circular Quay、北岸与 Manly；室外和可公开进入的室内同步制作。本版实际完成下列改动，**尚未完成全区 1:1**。原始地图位置、照片所见外观、估算尺寸与尚缺的数据分别记录，不能用建筑数量或自动测试通过替代现实精度验收。

## 106 处步行区域恢复完整铺面

原渲染器把 `highway=pedestrian + area=yes` 的闭合区域当成一圈道路，只沿边界生成路带。现按原多边形三角化：保留凹边界，避免把附近车行路、建筑或地铁开口一起铺平。面积与线状步道、车行道路相接时裁切交叠。车辆新增选位不再把广场外围当成道路中心线。大地图和小地图共用同一份区域几何。

当前源快照包含 CBD 97 处、北岸 6 处、Manly 3 处，共 106 处明确地面步行区域，合计 99,680.026 m²、2,279 个三角形。Pitt Street Mall、Henry Deane Plaza 和 Manly 部分公共前场在其中。只比较这 106 个源区域：旧边缘路带漏掉内部 37,244.361 m²，同时伸出原边界 79,390.972 m²。这个数不是整座城市全部道路的净漏铺面积；相邻其他路段或公园可能已经提供部分铺面。

原来的 19,680 条道路记录的 ID、节点坐标及标签均保持；15,508 条建筑轮廓/分体记录、树木、岸线、地铁开口和其他地图数据不变。新编译器支持显式内环，但当前导入快照没有获取完整的步行区域 multipolygon relations，不能声称所有广场、花园或院落都已恢复。

## Manly 公共大厅与街道

实照支持的改动包括 Wharf 正门标牌朝向、钟塔横板/钟面、公共前厅的深色屋架与木色顶板、候船座椅和导视；Hotel Steyne 调整为照片中的浅色雨棚及街侧阳台。删除与真实树位无关的第二排重复环形座椅，补入三处真实饮水设施节点。

Wharf 公共大厅—Corso—Hotel Steyne 提供双向连续步行路线，地图继续保留原有位置与别名。公共大厅依据包含 2012 年历史照片，尚无完整现况室内测绘；登船高差、闸机、店内、客房和其余 Manly 街区未在本轮完整还原。饮水设施位置有地图依据，三个单体的精确外形仍为推定。[逐项照片与范围](MANLY_REFERENCE.md)

## QVB 公共首层

新独立模型依据公开保护管理计划中的照片及平面图制作铜穹顶、侧面拱窗、街门和 Grand Walk 公共通廊。25 个原地图轮廓/分体由专属几何替代，保留原结构损坏键。南北通廊与中央 George / York Street 横向公共通道实际贯通。

本轮只制作公开首层的主要空间；商户内部、地下层、上层完整交通、现实楼层高差和现况店铺名录尚缺完整还原。地图轮廓有来源，立面构件尺寸和部分高度仍是估计。[照片、平面图与模型范围](QVB_REFERENCE.md)

## 恢复被网格索引漏掉的建筑细节

完整场景审计发现部分结构把有索引的基础网格与手工三角形混用，导致后者不在最终绘制列表。共享构造器现在先展开原网格，保留法线、UV 和绕序，再合并。范围涉及 Quay 写字楼、CBA 首层和悉尼塔部分细节；达令区水上设施采用同样处理。原地理位置、构件尺寸、损坏 ID 不因此改变。自动检查以实际生成的面、面积与完整场景的绘制数据为依据，最终视觉仍需原生截图核对。

## 测量数据准备与存档

新增官方 NSW DEM 的离线提取工具和 CBD、Manly、机场三个小窗口，用于下一步地面高程校准。原始投影、AHD 高程、数据年代、许可和转换方式详见 [高程数据说明](ELEVATION_REFERENCE.md)。这些是开发参考，**本版游戏地形仍未接入 DEM**；裸地 DEM 也不能证明楼高、建筑外形或室内布局。

地图修订升至 7，新旧存档仍沿用格式 5。公共设施和 QVB 新实体会触发一次实际占用检查；QVB 保留的 OSM 损坏键按新碰撞壳体判断，不能继续把原整块建筑当成封闭大厅。普通建筑的实心占用处理不放宽；当前修订存档不会在每次加载时反复迁移。[存档规则](SAVE_MAP_MIGRATION.md)

存档读取也会在重置世界之前检查视角和累计时间：错误类型或无限值被拒绝，避免加载中途失败后覆盖原槽。旧存档缺失这些可选字段时继续使用原有默认值。

本版测试、最终导出应用的截图和可复现命令统一列在 [验证记录](TESTING.md)。所有游戏画面均为原始引擎截图；不分发参考照片、Google 地图瓦片或第三方城市模型。

## 晴日画面

参考用户指定的 GTA_SZ 的整体城市体验，新增摄影天空的环境照明和反射，使门框、柱廊、玻璃、金属和落地接触处更有层次。天空素材从 Poly Haven 官方取得并以 CC0 发布，详见 [来源](../licenses/DAYLIGHT_ENVIRONMENT.md)。性能档关闭接触阴影；城市比例与原来的地图位置不变。该改动改善渲染，不能代替缺失的真实楼宇立面、地形和公共室内，参照范围见 [GTA_SZ 对照](VISUAL_REFERENCE_GTA_SZ.md)。


## 无敌坦克与战斗机

新增原创 Harbour Bastion 履带坦克与 Aster F-27 双发战斗机，均免费新增并直接入座，可保留独立副本。坦克炮塔可旋转，炮管可在 −12° 至 +70° 之间俯仰；鼠标瞄准，Q/Z 和 R/F 可补充调整，X 或左键发射。战机最高 2,000 km/h，W/S 推力、A/D 协调转弯、R/F 俯仰、空格减速，X 或左键发射前向火箭；界面也提供发射按钮，按住 Option / Alt 可点击。

两类载具保留刚体碰撞，但生命和燃料保持满值。运动前扫过整车包络，撞击建筑后移除对应的真实构件和碰撞体；损坏沿用世界存档。新碎片保持物理表现，对撞碎它的无敌载具暂不产生反向卡阻。炮弹使用逐帧连续射线命中；爆炸由闪光、冲击环、烟尘、火花与碎片组成，弹体与效果数量有上限并循环复用。

这是游戏化破坏：现有结构按构件损坏，普通地图楼宇可能整块消失；未制作有限元断裂或完整结构坍塌。地面、匿名支撑和部分无碰撞背景植被不属于可破坏建筑构件，因此不将本版描述为已经能摧毁场景里的一切。参考来源与具体实现见 [坦克](TANK_REFERENCE.md)、[战机](FIGHTER_REFERENCE.md)、[武器](COMBAT.md)。

## 夏季时间与运行诊断

按悉尼夏季平均日出约 06:02、日落约 20:00 校准固定一天，默认 12 倍速，现实两小时完成日夜循环。T 面板可拖动时间、前后移动一小时、跳到日出或晚霞、调整速度或定格拍照。时刻、速度和循环开关随世界保存，旧存档有明确默认值；时间菜单释放鼠标并暂停驾驶。太阳、天空反射、雾色和窗灯随太阳高度变化。[天文基准与操作](SUMMER_CLOCK.md)

ICC 公开前厅、桥上部分现有灯头和歌剧院平台加入共 34 盏固定局部光源；昼夜仅改变能量，相应支撑损坏后停止照明。ICC 剧场前厅改用独立暖灰铺装材质，原楼板、碰撞与标高保持。灯具功率和部分投光位置为游戏估计，未完成全城路灯或真实光度测绘。[局部照明](PUBLIC_LIGHTING.md)

F3 面板显示实际绘制计数、内存、管线编译、玩家坐标、载具生成阶段耗时、材质和立面加载状态。数值调参立即生效，可恢复当前时段基准；用户调节以相对倍率随昼夜保留。统计数字不等于 GPU 耗时或帧率承诺。[诊断方法](RUNTIME_DIAGNOSTICS.md)

建筑材质按玻璃、石材、金属等角色集中调节，保持已有素材资源及各建筑原有颜色。普通楼体用稳定建筑种子生成夜间窗灯，同一栋楼的窗格不会每帧随机跳动，远窗逐步过滤。近距离立面细节使用工作线程和最多 64 个 160 米单元的队列；基础楼体、地面与碰撞仍常驻，这不是完整地图流式读取。[材质](MATERIAL_ROLES.md)、[立面加载](CITY_STREAMING.md)

新增载具会复用不可变的几何模板，每个副本仍有独立节点、涂装和碰撞；地图占用索引提前在启动时准备。改动来自实际分段计时，样本结果及仍有的启动、提交开销见 [性能记录](PERFORMANCE.md)。
