# Harbourlife 横屏项目宣传片

交付目标为 1920 × 1080、30 fps、H.264/AAC 的横屏主片，以及便于测试另一个开头的短版。片尾固定为“关注我，评论「悉尼」领试玩”。最终长度、分辨率、帧率和文件哈希以交付目录 `video-verification.json` 为准，不将脚本预设当成已验证结果。

## 内容与事实边界

主片依次呈现坦克开火和真实构件损坏、歌剧院与海港大桥、生产跑车驾驶、生产战斗机飞行及火箭、人物登上歌剧院台阶、公共室内和时间变化。普通城市场景保持实际游戏外观，不使用生成图片替换游戏镜头。海报如果采用图像生成，会单独标注为宣传设计。

源片段由 `trailer_capture.gd` 在实际世界完成加载后录制：生产输入/控制器、武器扫掠和时钟都继续工作；相机由脚本编排。画面经本机 loopback 传到 `capture_trailer.py` 并直接编码，不记录冗长的启动黑屏，也不写入全部原始帧。每段保存开始/中间/结束的真实关键帧以及演员位置、速度、开火、命中、损坏 ID 和时钟状态。移动镜头仍调用生产近景流式加载。

38 秒左右的展示段使用定时步长，不是实时 FPS 测试。日夜展示压缩调用了真实时钟设置，明确记录时间重映射；它不冒充正常 12 倍速下几秒走完整天。战斗机字幕不把该镜头实际速度说成 2,000 km/h。

字体与效果自动断言通过后还需逐镜头查看，特别是开炮和命中是否被树木、屋檐或烟雾挡住。被遮挡的镜头保留为试录记录，不作为宣传片验收。

## 制作工具与音频

`edit_promo.py` 将已接受的真实片段与 ASS 中文字幕合成。`promo_score.py` 生成原创器乐配乐，不采样现有歌曲；`promo_audio_export.gd` 导出生产武器合成器的声音，再按源片实际事件时刻混音。这是宣传片配音轨，不声称完整录下了游戏实时音频混音。字幕使用同许可 Noto 字体；无系统 TTS 语音或第三方音乐。

开发工具可在隔离环境安装 `imageio-ffmpeg numpy pillow`。FFmpeg 不随玩家 App 分发。完整输出需独立解码检查尺寸、帧率、总帧数、时长和音轨，并记录声音来源及脚本哈希。混音先做响度处理和限幅，随后重新测量压缩后的 AAC 真峰值；超过 −1 dBTP 的成片不接受，测量值随视频报告交付。声音数据与电平验证不代替实际听审。

正文：

> 歌剧院、海港大桥、街头超跑，还有能开火的坦克和战斗机。这个悉尼开放世界正在一点点做出来，现在已经可以免费试玩。
>
> 你最想先去悉尼的哪个地方？关注我，评论「悉尼」领试玩，一起把这座城造完。

建议话题：`#悉尼 #开放世界 #独立游戏 #游戏开发 #留学生活`

置顶评论：

> 想试玩的评论「悉尼」。目前是 Apple Silicon Mac 预览版，地图和建筑还在持续完善。也欢迎告诉我下一站最想看哪里。

另一个开头：**在悉尼开坦克，是什么体验？** 对应短版视频。先发布选定的一版，再依据后台实际播放、前几秒留存、完播、关注和有效评论判断下一轮修改；没有后台数据时不编造指标，也不购买虚假播放、赞或粉丝。未自动发布到抖音，未购买投流。
