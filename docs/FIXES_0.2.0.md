# v0.2.0 · 奶龙危机

现有悉尼地图加入可游玩的街区战斗循环：遇敌、反击、获得金币、治疗与整备，再继续探索。没有基地建设。免费载具、城市工作、地标导航、昼夜、漂移和三倍加速保留。

- 五类统一黄色奶龙：游荡、疾跑、重装、喷吐、首领。攻击有前摇；喷吐有落点提示，首领有蓄力范围冲击。
- 怪物 Lv.1–10，越高级奖励越高。以游荡奶龙为例，Lv.1 为 120 金币，Lv.5 为 312；首领 Lv.1 为 1200，Lv.5 为 3120。每次击败只发一笔，清理一轮另有奖金及医疗包。
- 人物 120 生命，H 使用医疗包恢复最多 60，冷却 12 秒。倒下会触发付费救援，保留升级和剩余金币，不产生负债。
- 全部载具使用有限耐久；坦克和战机保留装甲与建筑破坏能力。损毁后失去动力和武器，E 离舱或 Home 求援。
- B 打开整备：停稳、与敌人保持 20 米安全距离、受伤后脱战 8 秒可交易。维修每缺 1% 耐久花 30 金币，能源每缺 1% 花 3 金币，医疗包 300。
- 坦克、战机三次火控升级分别需 8000 / 16000 / 28000，每级增加 25% 基础伤害并缩短装填。
- 同款免费副本共享耐久和升级，不能通过反复新增刷满血。远程维修会回收落水的未占用非船残骸，避免旧残骸持续拖坏修好的车队。
- 血条、怪物等级和击败金币可见；地图和整备菜单释放鼠标、暂停战斗，关闭菜单的那次鼠标点击不会误开枪。

存档格式为 6，保留旧世界、金币、载具和导航，同时保存生命、医疗包、敌人等级/血量、清理进度和车队升级。旧版程序无法读取新版写入的格式；更新前的存档恢复副本仍保留。

## 验证范围

使用实际生产脚本与 Jolt 物理，覆盖人物伤害、载具损毁、升级弹道、五型敌人、等级奖励幂等、医疗冷却、维修/补油收费、新副本与存档恢复。完整城市原生验证另外覆盖真实刷怪落地、攻击前摇、H/B 输入、坦克弹丸击杀到账和维修界面。详细结果随构建证据保存。

这些检查不等于长时间平衡试玩，也不代表已完成全悉尼 1:1 或多人模式。外观由程序模型制作；奶龙为既有角色，不声称原创角色 IP。
