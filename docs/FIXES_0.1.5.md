# v0.1.5-preview.1 · 歌剧院楼梯掉落修复

用户报告歌剧院大台阶与主体之间出现长条裂口并掉人。根因是旧版将最上方六级台阶的可见面和支撑都挂在单个 `opera/steps/7` 损坏组件上；它被撞毁时会移除整个宽 97 米、深 3.72 米的面，下面只有约 10 米低的地面。完整状态的楼梯与主平台坐标原本相接，旧测试却没有覆盖这段被破坏后的通行。

现将楼梯改成 8 条从地面填实到台阶下方的可见承重基座，饰面分成 64 小块。一块饰面受损后会露出实体基座，不再带走整幅支撑；顶端基座伸入主平台下方 80 毫米，完成面保持原来的高度和位置。平滑碰撞坡面与可见阶梯的差异最多为一个台阶高度，沿用游戏的上楼方式。

旧的 `opera/steps/0..7` 损坏标识退役并继续保留在历史记录中，不会匹配新基座，不要求删除存档或重开世界。原来的载具副本、资金和其它建筑损坏保留。若旧人物或载具位于新实体内部，地图升级会将其移到附近安全位置；地面上及高空的正常位置保持。

验证覆盖完整状态、加载旧台阶损坏状态、局部撞击后的全宽支撑，以及实际人物和平衡车上下楼。最终下载包的证据与范围见 [验证记录](TESTING.md)。本修复没有改变歌剧院其它屋壳或室内布局，仍不是完整现实测绘模型。
